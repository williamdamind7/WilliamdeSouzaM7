### ⚡ Sobre Mim
Sou graduado em **Redes de Computadores**, com foco em alta disponibilidade, segurança e ecossistemas Multi-Cloud. Minha atuação transita entre a robustez da infraestrutura crítica, cibersegurança (EDR/XDR/MDR), desenvolvimento de software e criação de experiências web avançadas.

- 🔭 **Foco:** Automação de infraestrutura, Multi-Cloud, Containers e Segurança de Endpoint/Borda.
- 🌱 **Aprendendo:** Arquiteturas Serverless avançadas, Inteligência Artificial e Ciência de Dados.
- 💬 **Expertise:** Cloud Computing, Virtualização, Painéis de Hospedagem, Desenvolvimento e Web Design (Wix Studio Expert).
